# রেজাউর টি স্টল

পাড়ার একটি ছোট চায়ের দোকানের ওয়েবসাইট। এটি শুধু HTML আর CSS দিয়ে বানানো — কোনো ফ্রেমওয়ার্ক বা বিল্ড টুল নেই।

Live site: https://rejaur2287.github.io/tea-shop-site/

## Pages

| পেজ | ফাইল | কী আছে |
|---|---|---|
| হোম | `index.html` | দোকানের ছবি, ছোট পরিচিতি এবং পুরো মেনু — চা ও পানীয়, হালকা নাস্তা |
| পরিচিতি | `about.html` | দোকান সম্পর্কে তিনটি ছোট লাইন |
| যোগাযোগ | `contact.html` | খোলার সময় ও ফোন নম্বর |

মেনুর সব আইটেম আর দাম সাইটেই আছে, হোম পেজে।

## How to Open

দুইভাবে সাইটটি দেখা যায়।

**১. সরাসরি ফাইল খুলে:** `index.html`-এ ডাবল ক্লিক করুন।

**২. লোকাল সার্ভার দিয়ে (রেকমেন্ডেড):**

```bash
cd tea-shop-site
python3 -m http.server 8000
```

তারপর ব্রাউজারে খুলুন: <http://localhost:8000>

বন্ধ করতে টার্মিনালে `Ctrl+C` চাপুন।
